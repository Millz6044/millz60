# Flex and the Three Doors

Interactive Halloween story for a kids' YouTube channel (ages 5–8), built from `assets/ep1-intro.mp4`.

- `story.md` – branching script (Ep 1 → 3 doors → finale)
- `shorts.md` – 5 vertical Shorts plans
- `metadata.md` – titles, descriptions, hashtags, schedule, Made-for-Kids notes
- `thumbnails/` – 3 thumbnail variants (1280×720 PNG; source in `thumbs.html`)

Note: Virale had no linked account, so virality choices are pattern-based. Link the channel and re-run for data-driven tweaks.
